PL/SQL Outline — 图标分类原型

四类家族：DB 对象（圆筒）· 主结构（文件夹）· 分支（菱形）· 循环（环箭头）｜图标 SVG 与 scripts/generate_icons.js 同源，所见即实现所得

分支 = 蓝色菱形 ◇（IF / CASE / WHEN / ELSIF / ELSE） 循环 = 琥珀环形箭头 ↻（LOOP / FOR / WHILE） 主结构 = 文件夹家族（Declaration / Body / Sub Program / Exception / 匿名块） DB 对象 = 圆筒家族（保持现状）
